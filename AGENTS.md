# AGENTS.md

This repo is public on GitHub.

## Private files

Anything that should not be public goes in `private/`, which git ignores. That includes invoices (JSON and PDF), client names, rates, other people's resume PDFs, and anything with personal or client details. Never commit these files anywhere else in the repo, and never remove `/private/` from `.gitignore`.

Before committing, check `git status` for files that belong in `private/`.
